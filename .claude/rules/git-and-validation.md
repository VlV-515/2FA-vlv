# Git and validation

- `swift build` and `swift test` must pass before commit.
- Run `./scripts/package-app.sh` when changes touch launch behavior, Info.plist, icon or release shape.
- One commit per coherent step. Message: `type(scope): summary`.
- No pushes, tags or releases unless the user asks.
- Generated outputs stay ignored: `.build/`, `.swiftpm/`, `dist/`.
- Icon assets (`Assets/`) are generated by `scripts/make-icns.sh`; commit the outputs after regenerating.
