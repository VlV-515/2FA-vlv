# Settings

Open with `⌘,`.

## General

| Option | Default | Notes |
| --- | --- | --- |
| Language | English | English (🇺🇸) or Español (🇲🇽). Applies instantly. |
| Hide codes until clicked | off | Click reveals for 10 s (also copies). |
| Show menu bar icon | on | Popover plus right-click menu. |
| Global shortcut ⌃⌥⌘2 | off | Show/hide the window from anywhere. |
| Launch at login | off | Uses macOS login items. May need approval in System Settings. |

## Security

| Option | Default | Notes |
| --- | --- | --- |
| Store secrets in Keychain | on | Off writes secrets in `vault.json` (0600). Switching migrates immediately. |
| Require Touch ID or password | off | Gate at launch, wake and auto-lock. |
| Auto-lock after | 5 min | Never, 1, 2, 5, 10, 15, 30 min. Needs the lock on. |
| Clear clipboard after copy | on | 10, 20, 30 or 60 s. Only clears if the clipboard still holds the code. |
